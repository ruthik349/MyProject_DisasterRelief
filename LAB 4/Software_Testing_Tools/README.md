# LAB 4 — Software Testing Tools: Fruit Catcher

This folder contains the Fruit Catcher Pygame project and before/after evidence. The original assigned starter/fork is [ruthik349/64_fruit_catcher](https://github.com/ruthik349/64_fruit_catcher).

## Fix applied in the consolidated copy
- Catching a fruit awards one point.
- A fruit that reaches the floor deducts one life and awards no points.
- When lives reach zero, the game enters `GAME_OVER` and stops updating.
- Existing restart behavior with the R key remains.

Run:
```bash
pip install pygame
python main.py
```
